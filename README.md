# FastAPI Learning 🚀

This repository contains my learning journey with **FastAPI**.  
I am using this repository to practice FastAPI concepts, build small examples, and document what I learn along the way.

## 📌 About FastAPI

FastAPI is a modern, fast Python web framework used for building APIs.

It is built on top of:
- **Starlette** – Web framework functionality
- **Pydantic** – Data validation and serialization
- **Uvicorn** – ASGI server
